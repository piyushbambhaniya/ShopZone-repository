# ShopZone

E-commerce college practical using HTML, CSS, JavaScript and Firebase Phone Authentication.

## Firebase setup
1. Enable Authentication.
2. Enable Phone provider.
3. Configure SMS region policy and allow India (+91).
4. Add your GitHub Pages domain under Authentication > Settings > Authorized domains.
5. The Firebase web config is already placed in js/app.js from the config supplied for this project.

## Important
- Real SMS OTP requires Firebase phone authentication to be configured correctly.
- The checkout is a demonstration; it does not charge a real payment.
- Product images are external image URLs. For a stable production site, download/use images you have permission to use and put them in an `images/` folder.
